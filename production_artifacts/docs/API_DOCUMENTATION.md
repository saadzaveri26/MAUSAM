# API Reference

Base URL (local dev): `http://localhost:8000`
Interactive Swagger UI: `http://localhost:8000/docs` (auto-generated by FastAPI)

## Reports

| Method | Path | Description |
|---|---|---|
| GET | `/api/reports` | List reports. Query params: `date_from`, `date_to` (YYYY-MM-DD), `event_category`, `state`, `city`, `verification_status`, `hide_duplicates` (bool, default true), `min_credibility`, `search`, `limit`, `offset`. |
| GET | `/api/reports/{id}` | Fetch a single report with full detail. |
| POST | `/api/reports/citizen` | Submit a citizen weather report. Body: `text`, `city`, `state`, `latitude?`, `longitude?`, `hashtags?`, `media_url?`, `media_type?`, `reporter_handle?`. Runs the full ML pipeline synchronously and returns the enriched report. |
| PATCH | `/api/reports/{id}/verify` | Admin verification action. Body: `status` (`Verified`\|`Rejected`\|`Auto-Flagged`\|`Pending`), `actor?`, `notes?`. Updates the report and the source's trust score. |
| GET | `/api/reports/meta/filters` | Returns distinct `states`, `cities`, and `event_categories` currently in the database — used to populate dashboard filter dropdowns. |

## Ingestion

| Method | Path | Description |
|---|---|---|
| POST | `/api/ingest/simulate` | Body: `count` (1-500, default 25). Generates a synthetic multi-source batch and runs it through the same ML pipeline as real ingestion. Used to demo real-time behaviour without live API credentials. |

## Analytics

| Method | Path | Description |
|---|---|---|
| GET | `/api/analytics/summary` | Headline KPI counts: total, verified, pending, auto-flagged, rejected, duplicates filtered, active/blacklisted sources, reports in the last hour. |
| GET | `/api/analytics/by-category` | Non-duplicate report counts grouped by `event_category`. |
| GET | `/api/analytics/by-state` | Non-duplicate report counts grouped by `state`, sorted descending. |
| GET | `/api/analytics/timeseries?days=14` | Daily report counts for the last N days. |
| GET | `/api/analytics/verification-breakdown` | Report counts grouped by `verification_status`. |
| GET | `/api/analytics/map-points?limit=500` | Lightweight point data (`lat`, `lon`, `category`, `severity`, `status`, short text) for the live map. |
| GET | `/api/analytics/sources` | Source credibility table: trust score, verified/rejected counts, blacklist status. |

## Example: submitting a citizen report

```bash
curl -X POST http://localhost:8000/api/reports/citizen \
  -H "Content-Type: application/json" \
  -d '{
        "text": "Heavy rainfall and waterlogging near Andheri station #IMD",
        "city": "Mumbai",
        "state": "Maharashtra",
        "latitude": 19.12,
        "longitude": 72.85
      }'
```

Response includes ML-derived fields:

```json
{
  "id": 181,
  "event_category": "Flooding",
  "category_confidence": 0.85,
  "credibility_score": 0.77,
  "severity": "Moderate",
  "verification_status": "Pending",
  "is_duplicate": false,
  "...": "..."
}
```
