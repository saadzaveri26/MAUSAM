From a hashtag to a verified data point

Every report — whichever source it comes from — moves through the same four-stage pipeline.

01

Ingest

Twitter/X posts tagged #IMD, citizen submissions, IMD/AWS station feeds, and news sources are pulled into a unified stream.

02

Classify

An ML pipeline tags each report's event type — rainfall, flooding, heatwave, cyclone, and more — with a confidence score.

03

Verify

A credibility model scores source trust and content signals, flags likely fake reports, and merges duplicates automatically.

04

Visualize

Verified, deduplicated reports land on the national map and analytics dashboard within moments of ingestion.

Built for the people who watch the sky for a living

Date, event & location filters

Slice the national feed by day, event category, state, or city — the same filters analysts use during an active weather system.

Verification tracking

Every report carries a status — pending, auto-flagged, verified, rejected — with a full audit trail of who verified it and when.

Duplicate & fake-report detection

TF-IDF similarity clustering merges re-shared posts of the same event; a credibility model catches clickbait and low-trust sources.

Live GPS-mapped events

Reports plot on an interactive map by category and severity, refreshing continuously as new data is ingested.

Citizen reporting

Anyone can submit a ground-level report with location, photos, and hashtags — feeding the same pipeline as social media.

Admin moderation console

Reviewers verify or reject flagged reports and track source credibility over time, retraining the trust model as they go.

Tech stack

Open-source, horizontally scalable, and swappable at every layer for production deployment.

Ingestion

  • Simulated multi-source connectors (prototype)
  • Designed for Twitter/X streaming API, IMD/AWS feeds, Kafka

ML / AI

  • scikit-learn — TF-IDF + Naive Bayes event classifier
  • Heuristic + feature-based credibility scoring
  • Cosine-similarity duplicate detection

Backend & storage

  • FastAPI (Python)
  • SQLAlchemy ORM over SQLite (prototype) → PostgreSQL/TimescaleDB (production)

Dashboard & frontend

  • HTML / CSS / vanilla JS
  • Chart.js for analytics, Leaflet.js for the live map
